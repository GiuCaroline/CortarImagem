O Cortador de Imagens é uma aplicação web desenvolvida para facilitar a divisão de uma imagem em várias partes de forma simples e intuitiva.

Ao acessar o site, basta selecionar uma imagem do seu computador. Em seguida, você pode posicionar e ajustar linhas paralelas sobre a imagem para definir exatamente onde os cortes serão realizados. Após confirmar a operação, a aplicação divide automaticamente a imagem em múltiplos segmentos, permitindo que cada parte seja baixada individualmente.

O projeto é ideal para quem precisa separar imagens em faixas, criar impressões em partes, produzir materiais gráficos ou organizar imagens em segmentos personalizados, tudo diretamente pelo navegador, sem a necessidade de instalar qualquer software.

## <img src="./imagesReadMe/scissors.png" width='23'> O que você encontra por aqui?

- Upload de imagens diretamente do computador.
- Posicionamento de linhas paralelas para definir os cortes.
- Visualização dos cortes antes da divisão.
- Geração automática das partes da imagem.
- Download individual de cada segmento.
- Interface simples, rápida e totalmente online.
